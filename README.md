# Optical Feature Maps for Small Language Models

Code for the research protocol (pre-registration: [research_question_v1.md](research_question_v1.md), never edited).
Current stage: **E0 (gate G1), E1 (Core baselines) and E2 (optical vs digital operators, gate G2)**.

## Run on Google Colab

1. Push this repository to GitHub (a private repo is fine).
2. For a private repo, create a GitHub fine-grained token with read access to that repo and add it in
   Colab as a secret named `GH_TOKEN` (key icon in the left sidebar).
3. Open the notebooks in `colab/` in order. In the first cell of each one, set `GITHUB_REPO` and
   (optionally) `WORKSPACE`, the Google Drive folder where splits, cache, run records and reports go.

| notebook | runtime | does |
|---|---|---|
| `01_splits_and_data_checks` | CPU | locked SciQ splits, option shuffle, leakage checks, χ², hashes |
| `02_extract_features` | T4 GPU | Pythia-160M + GPT-2 representations, layers L3/L6/L12/L12raw × mean/last pooling, determinism check |
| `03_e0_validation` | CPU or GPU | all unit tests + E0 report → gate G1 |
| `04_e1_baselines` | T4 GPU | zero-shot, linear probe, MLP head → Table 1 |
| `05_e2_operators` | T4 GPU | 9 feature maps × 2 D × 2 regimes × 3 seeds → Table 2, Figure 2, gate G2 |
| `06_e2_diagnostic` | T4 GPU | exploratory widened-grid E2 + linear-limit decomposition (see `deviations.md`) |
| `07_e2_v2_encoding` | T4 GPU | E2 under protocol amendment v2 (scaled phase encoding, knob τ) |
| `08_e3_placement` | T4 GPU | E3-A: layer × pooling × integration → frozen decision D-E3 |
| `09_e4_dimension` | T4 GPU | E4: accuracy vs D at D-E3 → Figure 3 |

Notebooks only call the scripts in `scripts/`, so anything can also be run from a terminal with
`OPTLM_WORKSPACE=/path/to/workspace python scripts/<name>.py --config configs/<name>.yaml`.

## Implementation decisions (beyond the protocol text)

- **Option shuffle:** seed 0, correct-answer position drawn as a balanced permutation, so each position
  holds exactly 1/4 of the correct answers in each official split.
- **Near-duplicates:** normalized question text only, token-Jaccard > 0.9, removed from train. The report
  also counts how many flagged pairs share the correct answer.
- **Layer 12:** `L12` = after the final LayerNorm (what the LM predicts from); `L12raw` = before it. Both cached.
- **Zero-shot:** per-token normalized log-likelihood is primary; per-character and unnormalized are also reported.
- **F-fourier:** d phases on the first d macro-pixels of a 28×28 SLM grid; the 16 padding pixels are
  illuminated (amplitude 1, phase 0); the SLM sits in a dark 64×64 window; unitary FFT; D camera pixels
  chosen at random (fixed per map seed). Energy test therefore expects Σr = 784 (and = 768 with dark padding).
- **Standardization:** per-dimension, train-pool statistics (no labels); constant features map to 0.
- **Sanity runs in E0** use a fixed λ = 1e-2 (no tuning, so no selection bias in the chance checks).
- **E1 MLP head:** only dropout is tuned (4 values) with weight decay fixed at 1e-2; early stopping on dev accuracy.
- **E2 maps:** B, C and D share one random matrix per map seed (they differ only in the nonlinearity); E uses
  R1, R2 ~ N(0, 1/(2d)) to match F-scatter's scale; H's σ is a multiple of √d because h is standardized.
- **E2 fits:** for each λ, the 10 paired subsamples are solved in one batched L-BFGS run (independent
  parameters, so identical to separate fits; verified in `tests/test_stats_batched.py`).
- **Statistics:** one shared paired bootstrap (10,000 resamples of subsamples and items) per panel; Holm across
  the F-row comparisons; gate G2 uses the uncorrected 95% CI as the protocol states.
- **E3/E4 runner:** `scripts/run_e2.py` also runs placement cells (`cells`, or `cells_from` the D-E3 decision),
  parallel integration ([h; r], both standardized) and E4's pre-registered D = 8d extension rule.
- **F-fourier above D = 4096** reads a 128 × 128 far-field grid (64 × 64 holds only 4096 camera pixels).
- Package versions are recorded in every run record instead of being pinned.
